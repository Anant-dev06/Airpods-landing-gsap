# 🎧 Apple AirPods Max — Landing Page

A modern, Apple-inspired AirPods Max landing page built with **HTML, CSS, JavaScript, and GSAP**. This project focuses on smooth animations, interactive elements, and a premium product presentation inspired by Apple's design language.

## 🌐 Live Demo

**[View Live Website](https://anant-dev06.github.io/Airpods-landing-gsap/)**

## ✨ Features

- 🎨 Clean, premium Apple-inspired UI
- ⚡ Smooth animations powered by GSAP
- 🌀 Scroll-based animation effects
- 🎧 AirPods Max product showcase
- 🖱️ Interactive website elements
- 📱 Responsive layout for different screen sizes

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- GSAP (GreenSock Animation Platform)

## 🎯 Project Goal

The goal of this project was to practice frontend development, explore GSAP animations, and create an engaging product landing page inspired by Apple's visual style.
